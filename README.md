# OIS 智物起源

**人人都是自己的 CEO。**  
Business Brain × Personal Agent

OIS 是一家面向真实生产力的 Agent Lab。我们关注 Agent 如何理解目标、持续执行并评估结果，成为能够协助人完成工作的伙伴。

> **大模型提供智能，Agent 将智能转化为行动，终端让 Agent 进入真实工作。**

## 公司介绍

我们从销售工作场景出发，初代产品方向是 **AI CRM + Personal Agent（Sales Work）**，核心形态是一部 **AI 工作手机**。我们希望让每一位销售拥有自己的 AI 团队，把更多时间投入到沟通、判断与促成合作。

我们的研究方向包括 **领域 Agent、支撑 Agent 的 OS 能力、端侧模型与 Post-training**。

**技术足够深，商业足够真。** 我们既重视技术深度，也尊重用户价值与商业结果。

> **我们要做的不是“更会聊天的 AI”，而是“真正能把事情做成的 AI”。**
