01产品场景

从销售工作出发

我们的初代产品方向是 AI CRM + Personal Agent（Sales Work），核心形态是一部 AI 工作手机。

销售工作涉及客户信息处理、持续跟进、方案整理、商机分析与跨 App 协作。这些任务彼此关联，需要从理解信息走向持续行动。

我们的研发目标，是让 Agent 承担其中重复而有价值的工作，让人专注于理解需求、建立信任与做出判断。

我们要做的不是“更会聊天的 AI”，
而是“真正能把事情做成的 AI”。BUSINESS BRAIN × PERSONAL AGENT
02能力目标

从理解目标，
到完成工作

理解目标、构建上下文、检索记忆、调用工具、持续执行并评估结果，是我们希望 Agent 具备的能力。

围绕这些目标，我们关注三个相互关联的工程议题。

01

目标、上下文与记忆

一项工作有自己的目标、背景和相关信息。我们希望 Agent 能够围绕当前任务构建上下文、检索相关记忆，让后续行动建立在对工作情境的理解之上。

Context 与 Memory 的价值，要回到它们是否帮助 Agent 更好地完成工作。

02

工具调用与持续执行

从整理信息到执行跟进，从单个工具到必要时的跨应用操作，我们希望 Agent 能够持续采取行动，把任务向前推进。

Agent Runtime、GUI Agent，以及连接软件与终端的能力，都与这一目标相关。

03

结果评估与持续改进

把事情做成，需要回到结果中接受检验。

长期来看，我们希望积累真实任务轨迹与反馈，通过 Post-training 改善 Agent 的表现，让它在具体工作中越做越专业。

03研发方向与取舍

把资源投向关键能力

我们的研究方向包括：

领域 Agent

面向具体业务任务，以销售场景作为产品起点。

Agent OS

研究支撑 Agent 的 OS 能力，连接软件与终端。

端侧模型

探索更快、更近、更私密的端侧智能。

Post-training

探索从真实任务轨迹与反馈中持续提升 Agent 表现。

现阶段，我们不从零训练基础大模型，也不自主制造硬件。我们把资源集中于 Agent、软件与终端的结合，以及它们所能创造的生产力。
